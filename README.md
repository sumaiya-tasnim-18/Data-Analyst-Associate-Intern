# Data-Analyst-Associate-Intern
This repository documents my first internship experience as a Data Analyst Associate Intern, completed over a 1-month duration. 

# 📖 Internship Overview
	•	Datasets: 6 raw datasets
	•	Database: PostgreSQL
	•	Tools: PostgreSQL, Excel, Figma, Looker Studio
	•	Focus Areas: EDA, ETL, KPI metrics, Dashboard design, Business logic analysis

# 📅 Weekly Breakdown
	•	Week 1: Imported raw datasets into PostgreSQL and performed initial EDA.
	•	Week 2: Created master table using SQL joins and carried out ETL for data cleaning.
	•	Week 3: Exported cleaned master table to Excel, identified KPIs, metrics, filters & drill-downs, and drafted dashboard wireframe in Figma.
	•	Week 4: Imported cleaned master table into Looker Studio, built final interactive dashboard, and presented the complete workflow in a virtual meeting.

🎯 Outcome

The project successfully delivered a data-driven, interactive dashboard providing actionable business insights. This internship gave me hands-on experience in data engineering, visualization, and presentation skills using real-world datasets and industry-standard tools.
